# Projeto Horizonte


## A Horizonte Soluções, uma empresa fictícia que comercializa produtos e presta serviços, cresceu rapidamente. Atualmente, seus colaboradores controlam clientes, produtos, pedidos e relatórios por meio de anotações e planilhas separadas. O resultado são cadastros duplicados, informações desencontradas e dificuldades para acompanhar a operação. 

## O projeto é um protótipo de um Sistema de Gestão Empresarial para visualizar, consultar, organizar, acompanhar e observar toda a movimentação da empresa. Contendo funcionalidades na página de módulos de clientes, produtos, pedidos e relatórios.

## Navegação entre as páginas disponíveis.
## Formulários para entrada e consulta de informações.
## Exibição e organização dos dados relevantes.
## Interface responsiva e de fácil utilização.
## Implementação de funcionalidades adicionais conforme os requisitos do projeto.

## Tecnologias utilizadas: HTML, CSS, JavaScript, Git e GitHub. Para visualizar o protótipo, é necessário um computador com navegador atualizado. O Visual Studio Code pode ser utilizado para editar e executar o projeto localmente.

## Fluxo de branches: o projeto utilizará a main como branch estável e a develop como branch de integração, além de seis branches de trabalho:

## feature/clientes
## feature/produtos
## feature/pedidos
## feature/relatorios
## fix/menu
## fix/visual
